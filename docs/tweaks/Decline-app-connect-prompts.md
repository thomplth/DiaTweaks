# Decline app connect prompts

When you open a site whose app Dia's chat can use, such as Notion, Slack or Linear, Dia stops you with a dialog asking to
connect it ("Connect Notion to Dia?"). This tweak answers **Not now** for you before the dialog appears, in every
profile, so you never see it.

It's the same answer as clicking **Not now** yourself, so Dia treats each app as declined. You can still connect an app
any time in Dia's settings, under **Apps**.

Turn it on in **Settings → Patches**, or with `diatweaks enable declineAppConnectPrompts`.
