# Color new tab groups

Dia starts every new tab group in its neutral color. With this tweak, a new group gets a random color as soon as it
appears, however it was made: from the context menu, by dragging, with a shortcut, by Dia itself or by Tidy Tabs.

The color is one that no other group in the profile is using. Once all seven colors are taken, it picks randomly among
the least used.

Groups that existed before you turned this on stay as they are, and so does any color you choose yourself, including
going back to neutral.

Turn it on in **Settings → Patches**, or with `diatweaks enable colorNewTabGroups`.
